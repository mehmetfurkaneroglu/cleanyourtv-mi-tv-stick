# Xiaomi Mi TV Stick (MiTV-AESP0, codename aquaman), Android TV 9 (SDK 28), firmware PI.2055, Turkey.
# Stock launcher: com.google.android.tvlauncher (disabled by launcher/build-and-install.sh).
# Built from examples/xiaomi-mitv-aesp0 on 31 Oct 2026, with the owner's choices: voice search, Chromecast
# (setupwraith stays on for it), firmware updates and the Mi video player kept; Mi Cast, Play Movies, YouTube Music
# and the screensavers off. Free memory went from about 175 MB to about 320 MB.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/xiaomi-mi-tv-stick-tr/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/xiaomi-mi-tv-stick-tr/debloat.txt com.google.android.tvlauncher
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Notes from this unit:
# - The remote (Bluetooth, vendor 2717 product 32b9) sends HOME for the round button and ALL_APPS for the 9-dot
#   button; HOME_KEY_SERVICE=1 keeps Home working and lets the More menu give the 9-dot button an app.
# - mitv.service was off on this unit without trouble (global firmware, Settings is com.android.tv.settings), but the
#   list leaves it on: only examples/xiaomi-mitv-aesp0 disables it, with the China-market warning.
# - The screensaver setting still names Google's backdrop after it is disabled: also run
#   `settings put secure screensaver_enabled 0` (undo: 1).
# - Closing ADB: USB debugging off alone leaves 5555 open; the Developer options master switch and a reboot close it.
